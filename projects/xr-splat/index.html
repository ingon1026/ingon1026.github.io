Gaussian Splatting 기반 XR 공간 재구성·위치추정

360° 영상과 RGB-D SLAM 두 방식으로 XR 공간 재구성과 실내 위치추정을 구현·검증.

개요

  • 기간: 2026.05 – 2026.07 (K3I)
  • Gaussian Splatting 기반 XR 공간 재구성을 360° 영상과 RGB-D SLAM 두 방식으로 구현·검증
  • 공간 촬영 한 번으로 실사형 3D 공간 자산과 실내 위치추정을 생성

자체 촬영 로비 공간 — 360° Gaussian Splatting 자유 시점 렌더

① 360° 영상 기반 재구성

  • Insta360 촬영 영상 → OpenSfM 카메라 Pose 추정 → MVS Dense Point Cloud 생성 → Gaussian 초기화
  • Sparse 대신 MVS Dense 초기화를 적용해 held-out PSNR +2.3 dB, floater 대부분 제거
  • 자체 촬영 2개 공간: SfM 등록 142/142 · 149/149, Test PSNR 19.70 / 19.99 dB

OpenSfM·MVS Dense Point Cloud와 카메라 궤적

② RGB-D SLAM × Gaussian Splatting

  • ORB-SLAM3(Pose·Loop Closure·Relocalization)와 gsplat(렌더)을 분리 구성, SLAM Pose를 고정 입력으로 공유
  • 두 맵이 동일 SLAM Pose에서 생성되어 별도 정합 없이 동일 좌표계 공유
  • RGB-D 녹화 하나에서 3D 공간 자산 + 실내 위치추정을 동시 생성

Gaussian 맵 내 카메라 Pose·Localization
